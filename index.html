About this data

This is a single self-contained HTML file, deployed at hendrychy26.github.io/crypto-screener and equally runnable by opening the file locally. Either way it calls public APIs directly from your browser: Crypto.com and Bybit for live tradable price/perp data, and CoinGecko for the fundamentals-grade fields (market cap, ATH/ATL, dilution, multi-timeframe momentum) that make entry analysis possible. Nothing here needs a server, an API key, or a Claude connector — open the file and it just runs.

  • Verdict (Simple view) is the one thing to read, and it works identically on both tabs. Everything else in this file exists to produce it. Four states:
    • 🟢 Ready — passed every check; the What to do column gives the level to hold or the action to take.
    • 🟡 Watch — the structure is there but one check still fails, and it names which one (e.g. waiting on: regime CAUTION).
    • ⚪ Not yet — no setup or no base formed.
    • 🔴 Avoid — failed breakout, downtrend, or barely trades.
    Rows sort by verdict, so Ready floats to the top with nothing to configure. On Breakout a Ready means the full Tradeable checklist passed; on Accumulation it means a valid base that is liquid, not a BTC proxy, with a sane stop — deliberately not requiring regime = TRADE, because accumulating a quiet base during 🟡 CAUTION is the point of that tab. Only 🔴 STAND DOWN blocks it, since building alt positions while BTC breaks down is how you catch a falling knife. Uncheck Simple view for the full expert table behind it.
  • Every mode was rebuilt around CoinGecko's richer per-coin data so the columns answer entry questions directly, instead of proxying them from 50-300 candle bars: is this move confirmed or a wick (7d momentum alongside 24h), is it extended or fresh (real distance from all-time-high, not a 50-bar proxy), is today's push starting or already exhausted (24h range position), and is there a dilution trap waiting (FDV/market-cap ratio). A useful side effect: Breakout mode's score no longer waits on a candle fetch to populate — Score, Read, and most columns are ready the instant tickers load; only Trend, Trend(200), TF Agree, Donch(20) Dist. and Setup still need a moment.
  • Regime badge (top right) answers one blunt question before you look at a single coin: is this backdrop even worth taking longs in? It reads BTC's own 200 EMA trend plus whether BTC dominance is rising or falling (approximated by comparing BTC's 24h market-cap change against the total crypto market's 24h change, via CoinGecko's /global endpoint), and collapses that into three states — 🔴 STAND DOWN when BTC itself is in a downtrend (most alt longs lose here regardless of setup quality), 🟡 CAUTION when BTC is up but capital is rotating into BTC rather than alts (dominance rising) or the trend is genuinely unclear, and 🟢 TRADE when BTC is up and not starving alts of capital. Hover it for the full reasoning. It doesn't filter or score any row automatically — it's a check to run before trusting a green score, the same way a discretionary trader checks BTC before sizing into an alt.
  • TF Agree compares the primary Candles timeframe's trend against the complementary one (Daily when you're on 4H, or 4H when you're on Daily) — a fresh 4H uptrend that the Daily still disagrees with (⚠) is a much weaker case than one both timeframes confirm (✓). This is exactly the "don't take a 4H long fighting the daily trend" check a discretionary trader runs by eye on two chart tabs; here it's automatic on every row.
  • BTC Corr is this coin's rolling correlation to BTC — bar-over-bar % returns compared over the last ~30 bars at whichever Candles timeframe you're on, not an all-time figure, so it reflects the current regime rather than history. HIGH (≥0.7) means it's mostly moving because BTC is moving; LOW (<0.3) means its moves are largely its own. When correlation is low and the coin's 24h move is the opposite sign of BTC's own 24h move — BTC down while this pushes up, or vice versa — it's flagged 🔀 as genuinely diverging: real idiosyncratic strength or weakness, not just beta to BTC. Also called out directly in the Read column and searchable via diverging.
  • Breakout (Breakout tab) answers "did this already break out, and if so is it holding?" — separate from Setup, which only looks at the pre-breakout coil. It scans back up to 30 bars for the most recent close above the rolling 20-bar Donchian upper channel computed from the bars before it (a genuine breakout event, not just "near the top of the range"), then checks whether price has held above that trigger level since:
    • 🆕 Fresh — triggered 0-2 bars ago, still tight.
    • ✅ Confirming — 3-15 bars ago, still holding above the trigger (pullback-and-hold, not a failure).
    • ⚠ Extended — 16+ bars ago, still above trigger but old news — chasing it now has worse R:R than the original breakout.
    • ❌ Failed — broke out, then closed back below the trigger — didn't hold.
    • — — no breakout detected in the lookback window at all.
    Every badge shows the actual watch level right in the cell — hold > $X (+Y%) for Fresh/Confirming/Extended, or reclaim > $X (−Y%) for Failed — X is the fixed trigger price from when that breakout was detected, Y is your live distance to it; hover for the fuller explanation. Also folded into Read/Why and searchable, e.g. confirming breakout or extended.
  • 🔔 Alert on ✅ Confirming notifies you when a coin enters the confirming phase, as an in-page strip plus a browser notification (permission is requested only when you tick the box). Confirming rather than Fresh on purpose: a single close above a level fails often — in a live scan of ~400 coins, failed breakouts outnumbered confirming ones roughly nine to one — while confirming means it survived a retest. One alert per coin, remembered in localStorage so reloading doesn't re-announce everything; the memo clears if a coin leaves the phase, so a genuine re-entry alerts again. Coins that turn confirming while alerts are off are memoized silently, so switching alerts on never dumps a backlog. Because it needs the tab open, there is also a cloud version that runs daily just after the 00:00 UTC candle close and pushes to Telegram — that one works with the laptop shut.
  • Tradeable (Breakout tab) is the highest bar in this screener and the one to act on. Setup only describes a shape; Tradeable asks whether that shape is worth risking money on today. It requires all of:
    • Structure — either a valid coil (✓ Coiled) or a live breakout still in 🆕 Fresh / ✅ Confirming. Failed and Extended breakouts are rejected.
    • Regime = 🟢 TRADE — a hard gate here, not the soft discount the Opportunity score applies. No longs screened during 🟡 CAUTION or 🔴 STAND DOWN.
    • Trend genuinely up (not merely "not down") and timeframes agreeing (✓, not just the absence of ⚠).
    • A stop you can size around — a 1.5x ATR(14) structural stop within 12% of price. (Originally 8%, which was calibrated off majors: on Daily crypto alts ATR alone is routinely 5-8%, so 1.5x ATR lands at 10-12% and the tighter bound rejected essentially every alt regardless of how good its reward:risk was.) Risk % is always shown so you can size down accordingly.
    • Not already chasing — no more than 15% above the trigger. A coin can be "confirming" by bar count while price has already run far past the level; bar count says early, price says the entry is gone.
    • R:R ≥ 2 — measured move (the Donchian range height projected from the breakout) divided by that risk.
    • Participation appropriate to its phase — volume drying up (≤1.2x) while still coiling, or expanding (≥1.3x) once triggered. These are deliberately opposite tests: a coil on rising volume is churn, and a breakout on flat volume is the textbook failure.
    • Real liquidity — $5M+ 24h volume and $20M+ market cap, so the spread doesn't eat the move.
    • Not a BTC proxy — |BTC correlation| under 0.85. Four signals all correlated 0.9 to BTC is one position at 4x size, not four positions.
    Passing rows show ✅ R:R 2.4 with the risk % beneath. Rows that fail show —; hover it to see exactly which checks blocked it, which is usually more informative than the pass itself. Note the volume test reads the last completed bar, never the still-forming current one — an early-in-the-day Daily bar always looks artificially quiet.
  • Setup (Breakout tab) is a strict, all-or-nothing pre-breakout checklist, shown as ✓ Coiled when every one of these holds: Donchian(20) width ≤10% (tight range), price sitting in the upper half of that range without having already broken out (55-97% channel position), RSI(14) 42-66 (healthy, not overbought or dying), 24h move ≤8% (hasn't already popped), trend not down, no TF Agree conflict, FDV/MCap ≤1.6x (limited dilution risk), and not flagged illiquid.
  • The "Early Entry only (strict)" checkbox (relabels itself "Valid Base only (strict)" on the Accumulation tab) hides everything that doesn't pass the checklist for whichever tab you're on — Breakout's pre-breakout coil checklist above, or Accumulation's own: ATH drawdown ≤-60% (a real discount, not a dip), within 20% of its own recent low, contracting range (volatility ratio ≤1.0x), quiet volume (Vol/MCap ≤5%), neutral RSI 35-60, limited dilution risk, liquid, and not still making fresh lows. These are deliberately different checklists for different jobs — a small, high-confidence shortlist rather than a soft ranking, because the point of either screen is precision over coverage. A coin still loading its candles is kept visible rather than hidden, the same way the Trend filter works, so the page has something to resolve.
  • Opportunity is a single 0-100 score folding the checklist above into one number. It drove the old Simple view; that role now belongs to Verdict, and this survives as a ranking aid in the expert table. It's mode-aware — Breakout and Accumulation compute genuinely different numbers from different inputs (coiled-near-highs vs. deep-and-quiet-base), so switching tabs changes the ranking, not just the label — and both are discounted by the current Regime verdict (a perfectly coiled coin during 🔴 STAND DOWN reads lower than the same coin would during 🟢 TRADE).
    • 🟢 Strong Setup / 🟢 Strong Base — 75+. High-confidence read; still confirm with the Setup/Valid Base checklist before acting.
    • 🟡 Building / 🟡 Basing — 50-74. Developing, not there yet — worth watching, not yet a trigger.
    • ⚪ Not Yet — 25-49. Doesn't meet enough of the checklist right now.
    • 🔴 Avoid — below 25, or illiquid/downtrend — floored low regardless of the rest of the inputs.
    Breakout tab labels: Strong Setup / Building. Accumulation tab labels: Strong Base / Basing. Same four numeric bands and same meaning either way — only the wording changes to match what the tab is actually looking for. Hover the pill for exactly which inputs feed it on the current tab. It's a ranking aid, not a signal — a high score still needs the Setup/Valid Base checklist (or your own chart read) to confirm before acting.
  • Market Cap and every new field are sourced from CoinGecko's public /coins/markets endpoint (top 1000 coins by cap, refreshed every 5 minutes) with the price_change_percentage extension for 1h/7d/14d/30d/200d/1y momentum. Matched to each row by ticker symbol — a handful of very obscure or newly-listed tickers may show — if CoinGecko doesn't rank them top-1000, or if a symbol collides with an unrelated larger coin sharing the same ticker (rare, resolved in favor of the larger-cap coin).
  • Dist. ATH is the real, exact distance from the coin's true all-time high (not a 50/300-bar proxy) — hover it for the ATH date. In Breakout mode, closer to 0% (near or at ATH) scores higher under the default weights: it confirms strength, though it also means less room before you're in genuinely new territory with no overhead resistance to reference. In Accumulation mode it's inverted — a deep, old drawdown (e.g. -70%+) is the "classic base" signal the Deep drawdown from ATH slider rewards.
  • 24h Range Pos. (Breakout tab) is where the current price sits between today's low_24h and high_24h — 100% means it's printing today's high right now (an active push), 0% means it's sitting at today's low despite a positive score elsewhere (worth checking why). This is intraday entry timing that a single 24h % change can't tell you.
  • FDV/MCap is fully-diluted valuation divided by current market cap — 1.00x means essentially all supply is already circulating (no dilution overhang); 3.00x means the market cap could effectively triple against you from unlocks alone even if the price never "goes up" in USD terms. This is a risk check, not a timing signal — a tight base with a high FDV/MCap can still be a trap. Low dilution risk (Accumulation) rewards ratios near 1.0x.
  • Vol/MCap replaces raw 24h $ volume everywhere — it normalizes conviction across market-cap sizes (a $50M coin doing $5M volume is louder, relatively, than BTC doing $300M) and is used as the "quiet volume" (Accumulation) / breakout volume signal (Breakout) instead of the old vs-14-day-average surge calculation.
  • 7d momentum sits alongside 24h everywhere in Breakout mode so you can read acceleration: 24h hot but 7d flat reads as an early move; 24h cooling while 7d is still way up reads as cooling off — both called out directly in the Read column.
  • Up to 300 bars of history for the technicals that still need real candles (RSI, Donchian channel width/position, Range Contraction, TF Agree, the 20-period and 200-period Trend filters) — Crypto.com's raw REST candlestick endpoint returns up to 300 bars per request. At 4H that's ~50 days; at Daily that's ~300 days. Whichever one you pick, TF Agree always fetches the other for the cross-check.
  • Trend(200) (Breakout tab) is a genuine 200-period EMA trend filter — price above a rising 200 EMA is Up, below a falling one is Down. The simpler 20-period Trend column (used everywhere, and as this signal's fallback when a coin has under ~210 bars of history) is unchanged.
  • Universe is spot USD/USDT pairs only, classified directly from Crypto.com's instrument list (inst_type: CCY_PAIR), filtered to exclude tokenized-stock, ETF, commodity and stablecoin listings using a manual blocklist. Click the × next to any row that doesn't belong to hide it permanently on this device.
  • Bybit perp availability is checked live against Bybit's ticker list on load, and verified by price, not just by ticker. Matching on ticker alone is genuinely dangerous: Crypto.com's ADI trades around $8.76 while Bybit's ADIUSDT.P is an unrelated asset near $380 — 43x apart. Left unchecked, the technicals get computed from one asset while the chart link sends you to another, which looks exactly like a working screener right up until you trade it. A perp now only counts as the same coin if the two venues agree on price within 25% (real spot-vs-perp basis is under a couple of percent, so this only catches genuine collisions); mismatches are dropped from the Bybit perp only filter. Currently affects ADI and EDGE.
  • Composite score ranks each coin 0–100 on each metric relative to the current filtered set, then blends those ranks using the sliders above — it updates instantly as you drag, no refetch needed. Market Cap and Market Cap Rank are shown for reference only and never enter a composite score.
  • Your weights, page size and sort are saved automatically to this browser (localStorage — private to this device) and reload next time you open this file. Hidden rows persist the same way. Use Reset weights to go back to the defaults.
  • Preset dropdown gives one-click weight combinations per mode — e.g. Breakout's New ATH Momentum leans hard on ATH proximity plus 7d confirmation, while Fresh Move (early) leans on 24h momentum and Vol/MCap conviction to catch a move before 7d catches up. Dragging any slider by hand switches it to Custom automatically.
  • Read is a plain-language, one-line summary generated entirely from the numbers already in that row — deterministic, no AI call. Hover it for the fuller version, which now includes the 7d %, ATH distance/date, range position, Vol/MCap and FDV/MCap where relevant. Search also matches Read — try a phrase like confirming breakout, near ATH, or deep discount.
  • Click any coin's name to open its Bybit USDT-perpetual chart on TradingView in a new tab. This is a different market than the Crypto.com spot price shown in the table, so levels can differ slightly.
  • "Hide illiquid" drops any coin where 3+ of its last 10 candles had zero trades — thin, barely-traded coins produce stale closes that distort every technical column, Trend especially.
  • Breakout / Accumulation modes run two different composite scores over the same live data, each remembering its own weights independently. Breakout (formerly split across a separate Breakout and Donchian tab — merged into one so there's a single place to manage weights for "is this a valid long entry") blends momentum, 7d confirmation, relative strength, Vol/MCap conviction, ATH proximity, 24h range position, 200 EMA trend alignment and Donchian breakout proximity into one score, with TF Agree, Trend(200), Donch(20) Dist. and the strict Setup checklist all shown alongside for entry-quality context. Accumulation looks for the opposite: coins quietly basing far below their ATH with shrinking volatility, a tight Donchian channel, and low dilution risk.
  • Status — click the ● live indicator at the top to see every data feed separately: prices, coin list, candles, market caps, regime, BTC series and Bybit perps, each with when it last answered and what breaks if it doesn't. The headline reads live only when everything critical is fresh; live · partial means prices and candles are fine but a supporting feed (usually CoinGecko) is behind; data stale and data problem mean verdicts on this screen may be computed from old or missing data and should not be traded off until it clears. This matters because a screener that looks alive while a feed is silently dead is the worst possible failure mode — the numbers still render, they're just wrong. Both public APIs rate-limit by IP, so failures here are usually temporary; everything retries on its own.
  • Rate-limit backoff — Crypto.com 429s the candle endpoint, and because a 429 arrives without CORS headers the browser can only report it as a generic network failure. Failed candles are retried on a per-coin backoff (15s doubling to 5 min) behind a shared cooldown (5s doubling to 80s) that pauses both candle queues, and the cross-timeframe queue never runs while the main one is working. Without those brakes, one 429 fed the next: every re-render re-queued every failed coin at roughly 14 requests a second, keeping the page permanently rate-limited by its own retries.
  • This file makes outbound requests only to api.crypto.com, api.bybit.com and api.coingecko.com — all read-only market-data endpoints. It sends nothing about you; it just reads prices.
  • CoinGecko key (optional, in the filters panel) removes the main source of flakiness in this tool. Without one you share a public IP allowance of roughly 5-15 calls a minute, which a full scan trips constantly — and CoinGecko returns those 429s without CORS headers, so the browser reports them as generic network failures rather than rate limits. That is why market caps sometimes come back blank and the regime reads "unmeasurable". A free demo key from CoinGecko's developer dashboard gives you your own allowance and makes the tool markedly more reliable. It is stored only in this browser's localStorage and never written into the page, which matters because this file is served from a public repository — a key committed here would be readable by anyone and your quota would be theirs to spend.
